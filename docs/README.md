# Paperflow 文档中心

[返回项目首页](../README.md)

这套文档面向服务器 Web 发行版 **0.9.0**。第一次使用按下面的顺序阅读；已经部署过的用户可以直接进入维护或排错。

## 第一次部署

1. [安装教程](server/install.md)：准备服务器、安装程序、配置 HTTPS、登录并验证任务。
2. [配置说明](server/configuration.md)：密码在哪里改，数据源需要什么配置，下载参数有什么含义。
3. [网页使用](usage.md)：检索、任务进度、文献库和结果目录。

## 部署之后

| 文档 | 内容 |
|---|---|
| [服务器维护](server/operations.md) | 服务状态、日志、版本、升级、备份与迁移 |
| [故障排查](server/troubleshooting.md) | 按现象定位安装、网络、任务和存储问题 |
| [AI / API](api.md) | 认证、提交任务、轮询、获取论文和文件 |
| [数据库 CLI](database.md) | 表结构、查询、指标导入、去重和旧数据导入 |
| [项目结构](project-layout.md) | 源码目录、服务安装位置、持久化数据位置 |

安装教程的命令在 **服务器的 SSH 终端** 执行，只有标为“本地电脑”的步骤例外。`paperflow.example.com`、`SERVER_IP` 等都是需要替换的示例值。源码目录、安装目录、数据目录是三个不同的地方，不能混为一谈。
