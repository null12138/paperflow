AI RESEARCH API

让 AI 查论文、下全文。

所有接口返回 JSON，任务支持后台运行。使用当前网站的 Basic Auth 凭据即可访问。

调用流程

GET /api/v1/papers 查询已有文献库。发现新论文请 POST 创建 metadata 任务，收到 202 后每 5 秒查询任务状态，直到 succeeded、failed 或 cancelled。成功后使用原关键词查询文献库；结果来自共享文献库，不是任务独占结果。DOI 下载任务成功后，读取 archive_url 下载压缩包；论文详情的 pdf_url 可下载单篇 PDF。所有文件请求也需要认证。

机器客户端发送 application/json 和 Basic Authorization，无需 Cookie 或 CSRF token，请勿发送 Origin 或 Sec-Fetch-Site。浏览器请求仍需网页 CSRF token。limit 默认 0 表示不限量，建议首次设为 20。Europe PMC 检索可索引的全文（含正文与文后内容），WOS 与 PubMed 补充元数据检索；不覆盖所有付费正文，检索成功不保证每篇均能获取全文。

接口速览

GET  /api/v1
GET  /api/v1/papers?q=climate&limit=20
GET  /api/v1/papers/<paper_id>
POST /api/v1/jobs
GET  /api/v1/jobs/<job_id>
GET  /api/v1/jobs/<job_id>/archive

创建检索任务

curl -u USER:PASSWORD -X POST {{ request.url_root.rstrip('/') }}/api/v1/jobs \
  -H 'Content-Type: application/json' \
  -d '{"workflow":"metadata","items":["Ginkgo biloba"],"limit":20}'

创建 DOI 下载任务

{"workflow":"download","mode":"doi","items":["10.1000/example"]}
